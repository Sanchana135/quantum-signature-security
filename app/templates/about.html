Academic Disclosures & Model Boundaries

  • Classical Quantum-Inspired Computation: All algorithms in this platform are executed on standard classical CPU hardware using NumPy and scikit-learn. The term quantum-inspired denotes mathematical formulations derived from quantum state superposition and Born-rule probability amplitudes, not quantum physical hardware (such as superconducting qubits or ion traps).
  • Cryptographic Proof vs. Threat Heuristics: Cryptographic verification is strictly deterministic: either the signature mathematically satisfies \(\text{Verify}(pk, m, \sigma) = \text{True}\) or it fails. A machine learning or quantum-inspired anomaly score is an operational risk metric for SOC triage, and must never be presented as mathematical proof that a signature is forged.
  • Key Trust Invariant: Validating a digital signature confirms mathematical consistency between the key and message. It does not establish identity authenticity unless backed by a trusted Public Key Infrastructure (PKI) or certificate authority chain.
  • Post-Quantum Cryptography (PQC): This prototype evaluates classical RSA-PSS signatures. It is not an implementation of post-quantum lattice-based algorithms (such as NIST FIPS 204 ML-DSA/Dilithium or FIPS 205 SLH-DSA).

1. Quantum-Inspired Amplitude Projection Formula

Traditional signature verifiers return only a boolean result (\(\text{true}/\text{false}\)), ignoring behavioral and telemetry context. We model multi-dimensional verification telemetry into a 2-level quantum state space spanned by the orthonormal computational basis \(\{|0\rangle, |1\rangle\}\), where \(|0\rangle\) represents the Nominal Ground State and \(|1\rangle\) represents the Anomalous Threat State.

Step A: Normalized Feature Vector

Security telemetry is normalized into \(x = [x_1, x_2, \dots, x_5]^T \in [0, 1]^5\):

x_1: Cryptographic verification mismatch (0.0 = Valid, 1.0 = Invalid)
x_2: Rolling failure velocity tanh(k / 2.5) across a 10-minute window
x_3: Request velocity clip((freq - 2.0) / 28.0, 0.0, 1.0)
x_4: RSA key modulus degradation (2048-bit = 0.0, 1024-bit = 0.6, <1024-bit = 1.0)
x_5: Format, entropy, or Base64 irregularity penalty clip(issues * 0.5, 0.0, 1.0)

Step B: Phase Angle Mapping & Superposition State

Each feature \(x_j\) is mapped to a quantum phase angle \(\theta_j \in [0, \pi/2]\):

θj = xj · (π / 2)
State Vector: |ψ⟩ = α |0⟩ + β |1⟩
where β = √( ∑j=15 wj · sin2(θj) )  and  α = √( 1 - β2 )

P(Threat) = |⟨1 | ψ⟩|2 = β2 = ∑j=15 wj · sin2(xj · π / 2)
Threat Score = 100.0 × P(Threat) ∈ [0.0, 100.0]
